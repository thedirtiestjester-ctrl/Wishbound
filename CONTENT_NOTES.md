# Content Notes

Wishbound uses an all-adult cast. The selectable transformed identities are ages 25, 26, 28, 29, 30, and 33.

The optional Lewd Reactions mode contains suggestive body/clothing awareness, lingerie references, flirtatious adult messages, romantic embarrassment, and implied prior adult relationships. It does not include graphic sex acts.

Artwork accepted into the game is given a Wishbound-native identity and context. Prior narrative labels are not used by runtime code. Image-level safety requirements still apply regardless of renaming or reassignment.
